# ☕ CoffeeTumbler

A modern and minimal coffee e-commerce landing page built using **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.  
Smooth animations, elegant gradients, and a sleek dark aesthetic — inspired by premium coffee brands.

---

## 🚀 Live Demo
[View Deployment](https://coffee-tumbler-jiu1.vercel.app/)  

---

## 🖼️ Features

- ⚡ **Vite + React** for blazing-fast performance  
- 🎨 **Tailwind CSS** for modern responsive design  
- 💫 **Framer Motion** animations for smooth transitions  
- 🧭 **Reusable components** (Hero, About, Products, Contact, Footer)  
- 🌙 **Dark theme aesthetic** with premium gradient tones  
- 📱 **Fully responsive** on all screen sizes
